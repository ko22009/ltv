# LazyTV: что сделано

Новое приложение Android TV, функции по образцу LazyMedia Deluxe 3.475 (разобран APK, см. `<папка проектов>\lazymedia`).
Этот файл — история решений и состояния. Что осталось сделать — `plan_future.md`. Что не делается и почему — `docs/not-doing.md`.

## Решения владельца (2026-11-02)
- Писать с нуля (Kotlin, Leanback), код LMD не переносить.
- Настройки применяются сразу, без перезапуска приложения.
- Слева списки: Фильмы, Сериалы, Мультики, Ужастики, 18+ (наполняются автоматически из соответствующих разделов сервисов).
- Страниц видеосервисов (раздел «ВИДЕОСЕРВИСЫ» слева, категории сервиса) в приложении не будет: решение владельца 2026-11-03, см. `docs/not-doing.md`.
- Источники: торренты через TorrServe, сайты как в LMD (HDRezka, Zona и др.).
- Проверка только в эмуляторе (`<Android SDK>`, AVD `tv`), на приставку <приставка> не ставить, пока владелец не скажет.
- Визуал дорабатывается позже.

## Разбор LMD (2026-11-02)
Строки в LMD зашифрованы; расшифровка: `<папка проектов>\lazymedia\build\jx\harness\decode.py` (jadx-исходники в `build\jx\sources`, расшифрованные `build\jx\dec`).
- HDRezka: служебный домен `hdrzk.org` отвечает только с заголовком официального приложения (`X-Hdrezka-Android-App`), зеркала закрыты Anubis. Подмену приложения и обход проверки не делаем.
- Zona: `android1.mzona.net/api/v1/` (поиск `search/<запрос>`, `movies/<name_id>`, `tvseries/<name_id>/season/<n>`, `video/<mobi_link_id>?client_time=`). Видео требует подписи `client_time` и UA `Zona/1.10.2` (подмена официального клиента) — не делаем.
- Octopus (UltraDox, `045.ultradox.click`): открытый сайт, поиск `index.php?do=search&subaction=search&story=<фраза как есть>` (слова без двоеточия не находят), на странице магнеты в `div.torrent` — подключён источником раздач «Octopus» (сидов сайт не даёт). Видео-плеер сайта (HDVB) работает по ключу LMD — не берём.
- Что не делается и что можно самому: `docs/not-doing.md`.
- TorrServe MatriX на приставке (<приставка>:8090) проверен запросами как у LazyTV: add, get, поток `stream ... &play` отдал 1 МБ за 2,6 с.
- KinoDB2: `api7ge.armadyne.xyz/v1/` (`search?query=`, `movie/<id>`, `movie/<id>/reviews`) открыт без заголовков, но отдаёт только описание и отзывы, потоков нет.
- Zombie (`api.zombie-film.live/v2/franchise`) и Seasonvar-zone (`api.variyt.ws`): потоки идут через сторонние плееры с проверкой Referer/Origin; не берём.
- Anilibria: открытый API (`anilibria.top/api/v1`) — подключён.

Сделано 2026-11-02 (вечер, другая сессия): дорожки аудио/субтитров в плеере показывают настоящие метаданные потока (язык, каналы, кодек, битрейт из `Format`), без заглушек — проверено на реальном multi-track HLS-потоке (три разные настоящие аудиодорожки). Иконки «Очистить»/истории в поиске заменены с эмодзи на векторные (`MenuIcons.DELETE`, `MenuIcons.HISTORY`). `DpiBypass.handshake()` теперь проверяет не только TLS-хендшейк, но и приход первого байта ответа — ловит случай, когда соединение открывается, но данные не идут.
Этот фикс не решил медленный CDN Anilibria (см. выше, ~0,6 КБ/с): прямой curl-тест реального TS-сегмента (3 релиза, разные CDN-узлы cache-cloud23/26, качества 1080p/480p) показал обрыв ровно на ~15 КБ **одинаково** что напрямую, что через ByeDPI — то есть это не блокировка по SNI/хендшейку, которую лечит обход. Собственный резервный прокси приложения (`n.thenewone.lol:29976`) на это соединение отвечает отказом (403). Вывод: похоже на ограничение именно этой сети/IP (dev-машина), не обязательно повторится на приставке — нужна проверка на `<приставка>` по команде «ставь» (чек-лист — `plan_future.md`).

## Сделано 2026-11-03 (продолжение: логотип, серии, просмотренное)
- Логотип: `LogoView` — слово «Lazy» и телевизор с белыми буквами «TV» внутри (без play-треугольника, как на присланной иконке); баннер 640×360 и иконка приложения 192×192 перерисованы, `app_name` — «Lazy TV».
- Серии: заголовок без «где нашлось» и без описания; русское название, отдельной строкой оригинальное (если отличается), отдельная подсказка про качество. Убраны пустые разделители.
- Rutube: одинаковые загрузки одного фильма схлопываются по нормализованному названию, году и длительности — в «ВИДЕО» остаётся одна карточка.
- Seasonvar: если сайт сам пишет «заблокирован для вашей страны» / «по просьбе правообладателя», приложение показывает понятное сообщение и не пытается обходить гео-блокировку; при ошибке/пустом списке есть кнопка «Искать торренты».
- Торренты: добавлен YTS (`yts.am`, открытый JSON, hash→magnet). Одинаковые раздачи из разных источников схлопываются по BitTorrent-хешу; результаты появляются по мере ответа источников, не после ожидания всех.
- Просмотрено: отметка ставится при открытии серии; карточка тускнеет, справа только иконка «✓» без подписи. Над списком две кнопки для выбранной серии: «Добавить в избранное / Убрать из избранного» и «Пометить просмотренным / Снять отметку». Три точки убраны.
- Избранные серии: хранятся в `episodes.xml`, показываются строкой «Избранные серии» в ЗАКЛАДКАХ, открывают список серий на нужной серии. Список обновляется по revision без перезапуска.
- Карточка: если постер не передан из списка, он подставляется из TMDB (`Details.poster`); проверено на прямом запуске DetailsActivity. Пока TMDB не отдал широкий backdrop, в шапке сразу показывается постер как мягкая обложка, затем он заменяется кадром.
- Плеер: нижняя полоса серий, как в референсе — кнопки «Серия 1…N», текущая подсвечена красным, пультом можно переключить серию без выхода из плеера.
- Плеер: ложный тост `ERROR_CODE_TIMEOUT` при выходе (release timeout) подавляется; ошибка остаётся только в логе.
