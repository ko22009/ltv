## 9. Из сайта LMD (lazycatsoftware.com), разбор 2026-11-03

На сайте нет списка функций — 7 постов 2018–2019, одна запись 2024, FAQ и страница Pro. Ценность там не в фичах
(их мы и так разобрали по APK), а в опыте поддержки: FAQ собран из реальных жалоб, посты 14/21/22 — про адреса
сервисов и трекеров, 19 — про плотность экрана, 15 — про синхронизацию, 23 — про встроенный плеер. Отдельно
полезен Telegram-канал LMD: релизы выходят каждые 2–4 дня, и почти все — «фикс источника/балансера/трекера»,
то есть в таком приложении главное — быстро менять адреса, а не добавлять функции.

- [x] **Адреса источников и трекеров из конфига, зеркала, перебор** (`RemoteConfig.kt`): один JSON задаёт `base`
      и `alt` для anilibria/seasonvar/rutube/rutor/octopus/torrentkino/nnm/videoplenka/bitsearch/yts/tpb/nyaa/jacred.
      Запросы идут по адресам по очереди, ссылки внутри ответа строятся от ответившего хоста. Обновление — кнопкой
      и тихо раз в сутки. Схема и пример — `docs/remote-config.md`, `docs/remote-config.example.json`.
- [x] **Свои адреса в настройках**: «Конфиг с адресами (URL)», «Обновить адреса из конфига», «Сбросить свои адреса»,
      «ANILIBRIA/SEASONVAR/RUTUBE: свой адрес» (главнее конфига). Без конфига работают встроенные адреса.
- [x] **Бекап файлом** (`Backup.kt`, Настройки → Данные): «Сохранить копию в файл» / «Восстановить из файла».
      В файл идут закладки по папкам, история, отметки просмотра, избранные серии, история поиска и все настройки
      (включая код родительского контроля и свои адреса). Кэш найденных источников не копируется. Нет файлового
      диалога на приставке — копия кладётся в папку приложения, путь показывается тостом; восстановление берёт
      последнюю оттуда.
- [ ] **Помощь и человеческие ошибки** (из FAQ). Сейчас пользователь видит текст исключения
      (`EpisodesActivity.kt:147`, `ServiceActivity.kt:96`, `PlayerActivity.kt:152`). Нужны подсказки: неверная дата

      карточек; на прошивках с неверной плотностью (RK3328, Android 8.1) интерфейс всё равно раздут. Нужен общий

- [ ] **«О приложении»** (сейчас только версия, `SettingsActivity.kt:192`): дисклеймер «поисковая машина по открытым

## 10. Помощь и понятные ошибки — следующий шаг

Зачем: в FAQ LazyMedia 8 жалоб из 10 — не баги, а понятные ситуации (сбилась дата, провайдер блокирует, час пик,
торрент закрыт правообладателем, TorrServe не запущен). Приложение должно объяснять это словами и предлагать
действие, а не показывать `SSLHandshakeException` или `ERROR_CODE_TIMEOUT`.

Правило текста: одна-две строки, без кодов и стектрейсов — «что случилось → что сделать» + кнопка действия.

### 10.1 Одно место для ошибок

- [ ] `Errors.kt`: `explain(throwable): Pair<String, Action?>` — единая карта исключений → текст и действие.
  - `SSLHandshakeException`, `CertificateExpiredException`, `CertPathValidatorException`, «Trust anchor» →
    «Не сходятся дата и время на устройстве. Проверьте время и перезагрузите приставку» + кнопка
    «Открыть настройки даты» (`Settings.ACTION_DATE_SETTINGS`).
  - `UnknownHostException`, `ConnectException`, `SocketTimeoutException` → «Сайт не отвечает. Включите обход
    блокировок в настройках или выберите другой источник» + «Настройки → Сеть» и «Искать торренты».
  - HTTP 403/451 → «Источник закрыл показ для вашего региона или по требованию правообладателя» + «Искать торренты».
  - HTTP 5xx / пустой ответ → «Сайт временно не работает. Попробуйте позже или другой источник».
  - Seasonvar «заблокирован для вашей страны» (уже есть в `Sources.kt:348`) → перевести на общий текст, чтобы
    формулировка была одна на все источники.
  - TorrServe: `ConnectException`/таймаут по адресу → «TorrServe не отвечает по адресу …» + «Изменить адрес»,
    «Скачать TorrServe» (сейчас только текст, `TorrentsActivity.kt:418`).
  - Плеер: `ERROR_CODE_*` → «Поток не открылся: <причина словами>» + «Открыть во внешнем плеере»
    (сейчас только код, `PlayerActivity.kt:152`).
  - Ничего не найдено → «Ничего не найдено. Попробуйте торренты» (сейчас `SearchActivity.kt:186`,
    `TorrentsActivity.kt:187`).
- [ ] Перевести на него все места, где сейчас печатается `it.message`: `EpisodesActivity.kt:147`,
      `ServiceActivity.kt:96`, `SearchActivity.kt:186`, `PersonActivity.kt:65`, `TorrentsActivity.kt:358`,
      `PlayerActivity.kt:152`, тост Jackett в `SettingsActivity.kt`.
- [ ] Где сейчас только текст без выхода — добавить кнопку действия (как уже сделано с «Искать торренты» при
      пустом списке серий).

### 10.2 Экран «Помощь»

- [ ] Пункт «ПОМОЩЬ» в левом меню под НАСТРОЙКИ (`MainFragment.kt`, там, где собираются `PageRow`).
- [ ] Разделы (по одной короткой странице или одному экрану со списком):
      «Сайт не открывается» (обход, прокси, гео-блок), «Видео не идёт» (кодеки, внешний плеер, качество),
      «Торренты и TorrServe» (адрес, клиент, сиды, закрытая раздача), «Звук и субтитры» (дорожки в потоке),
      «Дата и время», «Старые приставки: Android 6 и ниже» (системные сертификаты — https не работает, лечится
      только заменой сертификатов), «Куда написать» (контакт владельца — заполнить перед раздачей).
- [ ] Тексты — своими словами из FAQ LMD: короткие, без ссылок на чужие приложения.

### 10.3 Проверка даты на устройстве

- [ ] При старте (в фоне, один раз за запуск): взять `Date` из заголовка лёгкого ответа и сравнить с системным
      временем; расхождение больше суток → одна некритичная подсказка в ОБЗОРЕ или строкой в настройках,
      не модальное окно и не блокировка.
- [ ] Не пытаться «починить» часы: показать путь в системные настройки и объяснить, почему https не работает.

### 10.4 Как проверить

- [ ] Эмулятор, режим полёта: карточка фильма → серии и поиск дают понятный текст и кнопку «Искать торренты»,
      без технических строк.
- [ ] Сдвинуть дату на два дня назад → подсказка про время, а ошибка https объяснена словами.
- [ ] Остановить TorrServe → «не отвечает по адресу …» с кнопками «Изменить адрес» и «Скачать TorrServe».
- [ ] Битый поток в плеере → текст причины и «Открыть во внешнем плеере».
- [ ] Пультом: «ПОМОЩЬ» листается, кнопки в ошибках нажимаются, фокус не теряется.
