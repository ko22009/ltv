Единый список того, что осталось проверить вживую или отложено до появления внешних условий (живой сервер, приставка, новые открытые источники). История сделанного — в `PLAN.md`, что не делается и почему — в `docs/not-doing.md`.

- [x] **Адреса из JSON-конфига (`RemoteConfig`) и резервная копия (`Backup`)**: перебор зеркал, ручные адреса сайтов в разделе «Адреса сайтов», сохранение/восстановление данных файлом и напоминание о давности копии в разделе «Данные».
- [x] **Встроенный плеер (`PlayerActivity`, `Playback.kt`)**: выбор аудиодорожек и субтитров с реальными метаданными и галочкой текущей дорожки, учёт настройки «Озвучка по умолчанию», полоса переключения серий с автопрокруткой и отметкой «Просмотрено», автопереход на следующую серию, показ разрешения/кодека/битрейта/буфера в верхней строке, кнопка смены качества и скорости (`0.75×`..`2.0×`) в плеере, прямое управление пультом с ускорением перемотки (`10`/`30`/`60` с) и фокусируемым `SeekBar`, удержание панели на паузе, выход по двойному нажатию «Назад», сброс позиции в конце видео и диалог с причиной ошибки и кнопкой «Открыть во внешнем плеере».

## 2. Проверка вживую (осталось)

### В эмуляторе или с внешним окружением
- [x] Диалог ошибки воспроизведения в плеере на битом потоке (`Ошибка воспроизведения`, `Открыть во внешнем плеере`, `Закрыть`).
- [x] Сервер Jackett: ввод адреса и API-ключа, кнопка «Проверить Jackett», поиск раздач и схлопывание дублей по `btih`.
- [x] Конфиг адресов `RemoteConfig`: скачивание JSON по сети, обновление строки «Сейчас» и применение адресов.
- [ ] Автопереход на следующую серию в самом конце воспроизведения эпизода.
- [ ] Открытие потока во внешнем плеере (при установленном стороннем видеоплеере).

### На приставке `<приставка>` (только по команде владельца «ставь»)
- [ ] Установка APK и первый запуск.
- [ ] Настройки → Сеть → «Подобрать приём обхода» (рабочий приём ByeDPI в домашней сети).
- [ ] Воспроизведение потока Anilibria (проверка скорости CDN на сети приставки).
- [ ] Голосовой ввод с пульта на странице «Поиск» и на экране торрентов.
- [ ] Открытие страницы загрузки TorrServe в телевизионном браузере.
- [ ] Строка «Популярное» на домашнем экране лаунчера приставки.
- [ ] Замер плавности (`adb shell dumpsys gfxinfo ru.lazytv`) на страницах «Поиск», «Фильмы» и при открытии карточки.

## 3. Отложено или не требуется сейчас

- **Масштаб интерфейса для прошивок с неверной плотностью**: вся вёрстка экранов и карточек уже считается от ширины экрана в пикселях (`widthPixels / 1280f`), поэтому не зависит от системного `densityDpi` прошивки. Отдельный множитель масштаба поверх этого не вводится, чтобы не ломать 5-колоночную сетку (`docs/design-system.md`).
- **Новые сайты-источники**: открытых API без защиты и чужих ключей среди оставшихся сайтов LMD сейчас нет (`ZonaFilm` отдаёт рекламный ролик, остальные закрыты Anubis/Cloudflare/Referer — см. `docs/not-doing.md`).
- **Скрытие контента по странам, темы оформления, Cast, облачная синхронизация, автообновление**: отложены решением владельца (`PLAN.md`, `docs/not-doing.md`).
