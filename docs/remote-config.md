# Адреса источников из конфига (`RemoteConfig`)

Сайты меняют домены и заводят зеркала. Когда адреса зашиты в код, каждый такой переезд — это новая сборка и
установка APK на приставку вручную. Поэтому адреса вынесены в маленький JSON, который приложение скачивает само.

## Как это работает

1. **Приоритет адресов** для каждого источника и трекера:
   1. адрес, введённый вручную в настройках (`base_<id>`), — он главнее всего;
   2. адрес из скачанного конфига (`base`, затем `alt` по порядку);
   3. встроенный адрес из `RemoteConfig.kt` (последний рубеж; он же работает, если конфиг не задан).
2. **Перебор**: запрос идёт по адресам по очереди; если адрес не ответил (мёртвый домен, отказ соединения,
   ответ не разобрался), берётся следующий. Ссылки внутри ответа строятся от того хоста, который ответил.
3. **Обновление файла**: в настройках кнопкой «Обновить адреса из конфига» и тихо в фоне при старте, если
   последняя загрузка была больше суток назад. Неудачная загрузка ничего не стирает — остаётся прошлый файл.
4. **Без конфига** приложение работает как раньше: встроенные адреса на месте.

## Формат файла

```json
{
  "addresses": {
    "anilibria":   { "base": "https://anilibria.top", "alt": ["https://anilibria.example"] },
    "seasonvar":   { "base": "https://seasonvar.ru" },
    "rutube":      { "base": "https://rutube.ru" },
    "rutor":       { "base": "rutor.info", "alt": ["rutor.is", "rutor.lib"] },
    "octopus":     { "base": "https://045.ultradox.click", "alt": ["https://ultadox.space"] },
    "torrentkino": { "base": "https://torrentkino.org" },
    "nnm":         { "base": "https://nnmclub.to/forum/" },
    "videoplenka": { "base": "https://lafa.site" },
    "bitsearch":   { "base": "https://bitsearch.to" },
    "yts":         { "base": "https://yts.am" },
    "tpb":         { "base": "https://apibay.org" },
    "nyaa":        { "base": "https://nyaa.si" },
    "jacred":      { "base": "https://jr.maxvol.pro", "alt": ["https://jacred.freebie.tom.ru", "https://jac.stull.xyz"] }
  }
}
```

Правила разбора:

- `addresses` — единственная обязательная секция; всё остальное в файле игнорируется (можно класть `version`, `note`).
- `base` и элементы `alt` — адрес с `https://` или без схемы (`rutor.info` → `https://rutor.info`), хвостовой `/` отбрасывается.
- Идентификаторы, которых нет в файле, сохраняют встроенный адрес; незнакомые идентификаторы игнорируются.
- Пустой `addresses` (или файл без него) считается ошибкой: приложение скажет «В конфиге нет ни одного адреса» и
  оставит прежние адреса.

## Где взять адрес

Подойдёт любой HTTPS-адрес, отдающий этот JSON как есть:

- gist на GitHub — «Raw»-ссылка вида `https://gist.githubusercontent.com/<user>/<id>/raw/addresses.json`;
- свой веб-сервер или статический хостинг;
- собственный домен, если он есть.

Проверка: адрес открывается в браузере и показывает JSON, без авторизации и без редиректа на HTML-страницу.

## Что вписать в настройках

Настройки → **Адреса источников**:

| Пункт | Что делает |
|---|---|
| Конфиг с адресами (URL) | адрес JSON; пусто — работают встроенные адреса |
| Сейчас | откуда взяты адреса и когда обновлялись |
| Обновить адреса из конфига | скачать и применить сразу |
| Сбросить свои адреса | убрать адреса, введённые вручную |
| ANILIBRIA / SEASONVAR / RUTUBE: свой адрес | ручной адрес конкретного сайта (главнее конфига) |

Свои адреса для трекеров (rutor, Octopus и остальные) задаются там же, где и раньше: «Серверы JacRed» —
список серверов через запятую; остальные трекеры берут адреса из конфига.

## Ограничения

- Конфиг меняет только **адреса**, не разметку и не протокол. Если сайт сменил формат ответа, нужна правка кода.
- Адрес конфига хранится как настройка и попадает в файл бекапа: после восстановления на другом устройстве
  конфиг продолжит обновляться.

## Проверка вживую

Раздел «Адреса источников» отрисован в эмуляторе (uiautomator: заголовок, «Сейчас — Встроенные адреса»,
кнопки, строки «свой адрес» с текущими значениями). Скачивание конфига с реального адреса не проверялось:
адреса конфига пока нет. Проверять так:

1. положить `docs/remote-config.example.json` на любой HTTPS-адрес;
2. вписать адрес в настройках, нажать «Обновить адреса из конфига» — должен появиться тост
   «Адреса обновлены: 13 (…)», строка «Сейчас» смениться на «Из конфига: 13, обновлён …»;
3. испортить адрес в файле (например, `anilibria.top` → несуществующий домен), обновить конфиг и открыть
   карточку фильма: поиск по ANILIBRIA должен уйти на `alt`-адрес, а не упасть.
