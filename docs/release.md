# Релизы

Приложение распространяется файлом: готовый APK лежит в релизах на GitHub
(`https://github.com/ko22009/ltv/releases`), сайт `tv.sdkcache.ru` ведёт туда ссылкой. В Google Play не публикуем.

## Версия и имя файла

- Версия задаётся только в `app/build.gradle.kts`: `versionName` и `versionCode`.
- `versionCode` только растёт: по нему Android понимает, что это обновление поверх установленной версии.
- Имя файла: `LazyTV-<версия>.apk` (например, `LazyTV-1.0.0.apk`), тег релиза `v<версия>`, заголовок `LazyTV <версия>`.

## Выпуск

1. Поднять версию в `app/build.gradle.kts` (`versionName`, `versionCode`).
2. Собрать и разложить файл:
   ```powershell
   .\tools\release.ps1 -Version 1.0.0
   ```
   Скрипт соберёт `assembleRelease`, положит в `dist` файл `LazyTV-1.0.0.apk` и `SHA256SUMS.txt`.
3. Текст релиза поправить в `dist/release-notes.md`.
4. Опубликовать релиз (нужен установленный `gh` с входом в аккаунт):
   ```powershell
   gh release create v1.0.0 "dist/LazyTV-1.0.0.apk" --title "LazyTV 1.0.0" --notes-file dist/release-notes.md
   ```
   То же можно сделать руками на странице релизов GitHub: тег `v1.0.0`, файл из `dist`, текст из заметок.
5. В `docs/site/index.html` поправить номер версии и имя файла в разделе «Скачать» и выложить страницу на сервер.
6. Старые файлы из `dist` удалить: там лежит только текущая версия. Прошлые версии остаются на GitHub.

Ссылка на последний релиз, которую можно ставить где угодно: `https://github.com/ko22009/ltv/releases/latest`.

## Подпись

Сборка подписывается debug-ключом машины сборки: так обновление ставится поверх уже установленного приложения.
Ключ (`.android/debug.keystore` в домашней папке) надо сохранить: без него новые версии не встанут поверх
старых. Переход на другой ключ потребует удалить приложение у всех, кто им пользуется.

## Сайт

Страница сайта: `docs/site/index.html`, раздел «Скачать» ведёт на `releases/latest`. Стили и картинки рядом.
Выкладка на сервер описана в `docs/privacy-hosting.md`.

## Что проверить в релизе

- Номер версии на экране «О приложении» совпадает с тегом.
- Файл ставится на эмулятор Android TV и открывается с сохранёнными закладками (обновление поверх).
- Контрольная сумма в `SHA256SUMS.txt` совпадает с файлом.
