# Дизайн-система LazyTV

Правило: **новый экран собирается из готовых деталей этого списка.** Нужной детали нет — сначала добавляется
(или расширяется существующая) здесь и в коде, потом используется. Свои копии деталей в отдельных файлах запрещены.
Сделал новую деталь или изменил старую — обнови этот файл в том же коммите.

## Детали

| Что | Где в коде | Как использовать |
|---|---|---|
| Карточка фильма/сериала | `TitleCard`, `CardPresenter(cardScale)` в `Cards.kt` | Везде, где показывается постер с названием: ряды, «весь список», поиск, закладки. Свою карточку не рисовать. Режим выбора — `TitleCard.setPicked`. Нет постера в TMDB — заглушка `R.drawable.no_poster` («Нет картинки») |
| Плитка «весь список» / «искать торренты» | `MoreTilePresenter(cardScale)` в `MoreTile.kt` | Размер плитки равен карточке: подставляй тот же `cardScale` |
| **Кнопка** (единая) | `chipButton(context, scale, caption, icon?)` в `CatalogButtons.kt` | Любая кнопка: фильтры, сортировка (`CatalogButtonPresenter`), кнопки в шапке страницы поиска. Плашка `#39423D`, скругление 6, высота 44 (`CHIP_HEIGHT`), жирный 16, иконка 18, фокус зелёный. Свои кнопки не рисовать. Исключение: полоса кнопок под баннером на экране фильма (`DetailsActivity.button`): пять кнопок должны уместиться в одну строку, там плоские кнопки меньшего размера; их не менять на `chipButton` |
| Кнопка «Назад» | `backButton(context, scale, normalColor, onClick)` в `CatalogButtons.kt` | Круг `56×56`, стрелка `MenuIcons.BACK`, фон `#66000000` (на баннере `#99000000`), фокус зелёный (`focusShape(..., circle = true)`). Ставится слева в шапке каждого вложенного экрана (`TitlesGridActivity`, `PersonActivity`, `FiltersActivity`, `TorrentsActivity`, `EpisodesActivity`, `DetailsActivity`) для мыши и пультов без кнопки «Назад» |
| Скелетон карточки | `SkeletonCard`, `SkeletonCardView` (`Cards.kt`), `SkeletonPresenter(cardScale)` (`MainFragment.kt`) | Пока ряд или сетка грузится, в ней стоят серые карточки того же размера (как у `CardPresenter` с тем же `cardScale`), а не пустое место или крутилка. Настоящие данные приходят: `cards.clear()` и `addAll`. Есть в рядах «Обзора», сетке «Фильмы»/«Сериалы» |
| Плитка раздела настроек | `SettingsSectionPresenter`, `SettingsPageFragment` (`MainFragment.kt`) | Страница «Настройки»: единая сетка `titleCardGrid` в 3 колонки (стрелки вверх/вниз держат колонку, вправо в конце строки переходит на следующую строку) |
| **Сетка карточек** (единая) | `titleCardGrid(context, scale, bridge, columns)` и `titleGridParams(scale)` в `Cards.kt`; `TitlesGridActivity`, `CatalogPage`, `SearchPageFragment`, `PersonActivity` (фильмография): 5 колонок, `cardScale = 0.82` | Любая сетка карточек фильмов. Внутри: увеличение карточки при фокусе (`setupBrowseItemFocusHighlight`), запас 20 по бокам и 14 сверху (карточка при фокусе растёт на 15%), `clipToPadding = false` (увеличенная карточка рисуется в запас и не режется по краю страницы; при прокрутке карточки обрезаются по верхней границе грида, а грид начинается на 14dp ниже заголовка, поэтому остаётся зазор и карточка не налезает на заголовок). В страницу класть через `titleGridParams` (боковой запас уходит за поля страницы, карточки остаются на её краю). Свою `VerticalGridView` для карточек не создавать. Шаг колонок: `(ширина - (N-1)*6) / N + 6` целыми пикселями |
| Фон страницы | `calmBackground()` (`Background.kt`) | Все экраны, кроме плеера |
| Рамка при фокусе | `focusShape(scale, normal)` (`SearchBar.kt`) | Любой фокусируемый элемент вне Leanback-рядов |
| Строка поиска | `SearchBar(activity, scale, onSubmit)` (`SearchBar.kt`) | Круглая кнопка микрофона и поле ввода на экранах поиска и торрентов; фоновая догрузка источников показывается спиннером в правом углу поля через `setLoading(true)`, без отдельной прыгающей строки под полем |
| Иконки | `MenuIcons` (`MenuIcons.kt`) + `PathDrawable` | **Только Material или уже имеющиеся в проекте**, новые не рисовать. Корзина — `MenuIcons.DELETE` |
| Карусель актёров | `castRow` в `DetailsActivity` | Круглое фото, имя, роль |

## Цвета и размеры

- Фон страницы `#0C140F`; плашка карточки/плитки `#39423D`; плашка под карточкой `#12201A`.
- Фокус — зелёный `#2F7D57`; выбранный пункт меню `#2A5540`; светлый акцент (галочки, рейтинг) `#B9F6CA`.
- Текст: основной белый, второстепенный `#9FB3A9` / `#AFC4B6`, подписи таблиц `#8FB39D`.
- Единица размера — «dp экрана»: `ширина экрана / 1280` (`scale`), все отступы и кегли умножаются на неё.
- Верхний отступ страниц 48dp (`browseRowsMarginTop` в теме), нижний отступ рядов 6dp (`dimens.xml`).
- Меню слева: широкое при фокусе, при уходе фокуса — полоса иконок (`MainFragment.buildRail`).

## Правила UX для любого списка

- **Загрузка:** скелетоны размером с настоящий элемент; страница не «съезжает», когда приходят данные.
- **Пусто:** короткая надпись с подсказкой, что делать (закладки, «Ничего не найдено»), а не пустой экран.
- **Ошибка:** сказать, что не загрузилось (не молчать), экран не должен остаться пустым без объяснения.
- **Фокус:** на скелетон и подпись фокус не попадает; после загрузки курсор на первом настоящем элементе.
- **Сдвиги:** не двигать вид через `translation*`: за границей списка он обрезается и пропадает. Менять отступы.

## Перед новым экраном

1. Прочитать этот файл и найти подходящие детали.
2. Нет детали — расширить существующую (параметр, режим), а не копировать.
3. Проверить в эмуляторе рядом с соседним экраном: карточки, отступы и иконки должны совпадать.
