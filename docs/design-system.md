# Дизайн-система LazyTV

Правило: **новый экран собирается из готовых деталей этого списка.** Нужной детали нет — сначала добавляется
(или расширяется существующая) здесь и в коде, потом используется. Копия «по образцу» в своём файле запрещена:
так в поиске появились карточки, непохожие на остальные, и корзина не из LazyMedia.
Сделал новую деталь или изменил старую — обнови этот файл в том же коммите.

## Детали

| Что | Где в коде | Как использовать |
|---|---|---|
| Карточка фильма/сериала | `TitleCard`, `CardPresenter(cardScale)` в `Cards.kt` | Везде, где показывается постер с названием: ряды, «весь список», поиск, закладки. Свою карточку не рисовать. Режим выбора — `TitleCard.setPicked` |
| Плитка «весь список» / «искать торренты» | `MoreTilePresenter(cardScale)` в `MoreTile.kt` | Размер плитки равен карточке: подставляй тот же `cardScale` |
| Кнопка-«чип» над рядами | `CatalogButtonPresenter` (`CatalogButtons.kt`) | Фильтры, сортировка и подобное над рядами |
| Плитка раздела настроек | `SettingsSectionPresenter` (`MainFragment.kt`) | Страница «Настройки» |
| Кнопка в шапке страницы | `button(icon, caption)` в `SearchPageFragment` | Если нужна на втором экране — вынести в общий файл, не копировать |
| Сетка «весь список» | `TitlesGridActivity`, `SearchPageFragment`: 5 колонок, `cardScale = 0.82` | Тот же размер на всех страницах-сетках |
| Фон страницы | `calmBackground()` (`Background.kt`) | Все экраны, кроме плеера |
| Рамка при фокусе | `focusShape(scale, normal)` (`SearchBar.kt`) | Любой фокусируемый элемент вне Leanback-рядов |
| Иконки | `MenuIcons` (`MenuIcons.kt`) + `PathDrawable` | **Только из LazyMedia/Material**, новые не рисовать. Корзина — `ic_toolbar_delete` из LazyMedia |
| Карусель актёров | `castRow` в `DetailsActivity` | Круглое фото, имя, роль |

## Цвета и размеры

- Фон страницы `#0C140F`; плашка карточки/плитки `#39423D`; плашка под карточкой `#12201A`.
- Фокус — зелёный `#2F7D57`; выбранный пункт меню `#2A5540`; светлый акцент (галочки, рейтинг) `#B9F6CA`.
- Текст: основной белый, второстепенный `#9FB3A9` / `#AFC4B6`, подписи таблиц `#8FB39D`.
- Единица размера — «dp экрана»: `ширина экрана / 1280` (`scale`), все отступы и кегли умножаются на неё.
- Верхний отступ страниц 48dp (`browseRowsMarginTop` в теме), нижний отступ рядов 6dp (`dimens.xml`).
- Меню слева: широкое при фокусе, при уходе фокуса — полоса иконок (`MainFragment.buildRail`).

## Перед новым экраном

1. Прочитать этот файл и найти подходящие детали.
2. Нет детали — расширить существующую (параметр, режим), а не копировать.
3. Проверить в эмуляторе рядом с соседним экраном: карточки, отступы и иконки должны совпадать.
