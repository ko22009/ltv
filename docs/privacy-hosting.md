# Публикация страниц LazyTV

## Адреса

- Политика конфиденциальности: `https://tv.sdkcache.ru/policy`, исходник `docs/privacy/index.html`.
- Форма пожертвования: `https://tv.sdkcache.ru/donate`, исходник `docs/donate/index.html`. Отправляет 100 ₽ через
  ЮMoney; платёж не проверялся.
- Сайт приложения: `https://tv.sdkcache.ru`, исходник `docs/site/` (`index.html`, `style.css`, `images/`).
- Раздел «Скачать» на сайте ведёт на релизы GitHub: файлы APK на сервере не лежат, выпуск описан в
  `docs/release.md`.

## DNS и HTTPS

- В DNS поддомена `tv` запись `A` указывает на сервер сайта. Адрес сервера и доступ к нему держим вне
  репозитория.
- Поддомен обслуживается отдельным виртуальным хостом: `/policy` и `/donate` отдают свои страницы, остальное
  берётся из каталога сайта.
- HTTPS с сертификатом Let's Encrypt; после продления сертификата nginx перезагружается хуком обновления.

## Как выложить

1. Скопировать по SSH изменённые файлы в каталог сайта на сервере (адрес, пользователь и каталог описаны в
   памятке окружения, вне репозитория).
2. Проверить: страница отвечает 200, стили новые, раздел «Скачать» на месте.
