# Публикация политики конфиденциальности

## Адрес

- Публичная страница LazyTV: `https://tv.sdkcache.ru/privacy`.
- Исходник: `docs/privacy/index.html`.
- На сервере страницу положить в `<каталог сайта>/privacy/index.html`; конфигурация веб-сервера отдаёт файлы из `<каталог сайта>`, поэтому каталог `privacy` открывается по пути `/privacy`.

## DNS и HTTPS

Состояние на 12.11.2026, проверено при подготовке страницы:

- `tv.sdkcache.ru` не вернул A-запись при проверке; в DNS-панели <хостинг> нужно проверить, что записи ещё нет, и при необходимости добавить `A: tv -> <сервер>`.
- Текущий root веб-сервера: `<каталог сайта>`; основной конфиг виртуального хоста: `<nginx>/conf.d/nginx-sdkcache.conf`.
- После изменений проверить конфигурацию командой `nginx -t`, затем выполнить reload nginx и проверить `https://tv.sdkcache.ru/privacy` извне по HTTPS.


## Что осталось до публикации

1. Заменить `PRIVACY_CONTACT_EMAIL` в `docs/privacy/index.html` на настоящий адрес для обращений по конфиденциальности.
2. Проверить существующие DNS-записи в <хостинг> и добавить `tv` только если записи нет.
3. Обновить сертификат и серверный `server_name`, выложить HTML в `<каталог сайта>/privacy/index.html`, проверить HTTPS и доступность без авторизации и геоблокировки.
4. Сохранить этот же адрес в Google Play Console. В приложении пункт «Политика конфиденциальности» уже ведёт на него.
