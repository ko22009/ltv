# Публикация политики конфиденциальности

## Адрес

- Публичная страница LazyTV: `https://tv.sdkcache.ru/policy`.
- Исходник: `docs/privacy/index.html`.
- На сервере страница находится в `<каталог сайта>/policy/index.html`.

## DNS и HTTPS

Состояние на 12.11.2026, проверено при подготовке страницы:

- В панели <хостинг> добавлена запись `A: tv -> <сервер>`; распространение может занять до 30 минут.
- Отдельный виртуальный хост: `<nginx>/sites-available/lazytv-policy`, сертификат: `<сертификаты>/live/tv.sdkcache.ru/`. После продления сертификата nginx перезагружается через `<сертификаты>/renewal-hooks/deploy/lazytv-cert-reload`.
- Переход на форму пожертвования: `https://tv.sdkcache.ru/donate`, исходник `docs/donate/index.html`, на сервере `<каталог сайта>/donate/index.html`. Форма отправляет 100 ₽ через ЮMoney; платёж не проверялся.
- Проверено: `nginx -t`, HTTPS отвечает 200, HTTP перенаправляет на HTTPS, опубликованный HTML совпадает с исходником.

Политика опубликована 12.11.2026. Доступность без авторизации и геоблокировки из других сетей отдельно не проверялась.
