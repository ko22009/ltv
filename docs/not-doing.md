# Что не будет делаться и что можно сделать самому

Дата: 2026-11-02. Что в LazyTV не делается сознательно и почему.

## 1. Что не делается и почему

| Что | Почему |
|---|---|
| Страницы видеосервисов (раздел «ВИДЕОСЕРВИСЫ» слева, категории ANILIBRIA и SEASONVAR) | Решение владельца 2026-11-03: отдельные витрины сервисов дублируют каталог TMDB. Сервисы (ANILIBRIA, SEASONVAR, RUTUBE) остаются источниками: поиск идёт через них (`Sources.search`), найденное показывается в карточке фильма |
| Подмена личности официального приложения (чужие заголовки, подписи запросов, чужой User-Agent) для HDRezka и Zona | Это не отладка, а обход проверки доступа сервиса. Сервис пускает только своё приложение, и LazyTV им не является |
| Обход гео-блокировок (VPN, подмена страны/региона, чужие заголовки) | Это обход ограничения правообладателя. Если сайт пишет «заблокирован для вашей страны», LazyTV показывает сообщение и предлагает другой источник, торренты или официальный сервис |
| Обход проверки на ботов (Anubis на зеркалах HDRezka, капчи) | Такая проверка специально отсекает программы; обходить её нельзя |
| Потоки из сторонних плееров, закрытых проверкой Referer/Origin (Zombie, Seasonvar-zone) | LMD берёт их, выдавая запрос за страницу сайта-партнёра (чужие заголовки Origin/Referer, вид браузера Chrome). Это подделка личности для прохода проверки: тот же обход |
| RuTracker как источник раздач | Поиск у гостя закрыт входом в аккаунт, а страница поиска отдаёт проверку Cloudflare «Just a moment» (проверка на бота). Ни вводить чужой пароль, ни проходить проверку нельзя. Вариант самому: искать на сайте в браузере и добавлять magnet вручную |
| Плеер внутри Octopus (HDVB) и его ключ | Плеер работает по ключу, вшитому в LMD для самого LMD; чужой ключ не используется |
| Установка LazyTV на приставку <приставка> без слова «ставь» | Договорённость: проверка только в эмуляторе |
| Подбор паролей и вход на серверы по паролю | Только по ключу, без перебора (правило из `WORKING.md`) |
| Повторные подключения по SSH в цикле | Защита хостера закрывает доступ на минуты |
| Cast и вход через Google | Решение владельца 2026-11-02: пока не нужно |
| Синхронизация между устройствами, реклама, проверка обновлений вендора | Решение владельца 2026-11-02: не нужны |
| Filmix | Решение владельца 2026-11-02: не работал (партнёрский API LMD отвечает 403), убран |
| Из HD AlfaBox: Firebase-уведомления, рекламный идентификатор, автообновление из их канала | Слежка и чужой канал обновлений. Сам APK только разобран по ресурсам (код упакован защитой), не запускался |
| Автоподбор зеркала HDRezka (у HD AlfaBox проверяет 59 зеркал) | Нужен источник HDRezka, а он закрыт проверкой на ботов (см. выше). Появится только вместе с официальным доступом |

Как именно делать подмену или обход, здесь не описано и описываться не будет.

**Итоговое решение по HDVB/Zombie/Seasonvar-zone (2026-11-02):** владелец прямо просил «бери тот же ключ» для HDVB и те же заголовки для Zombie и Seasonvar-zone. Отказ окончательный: это не «взять тот же ключ», а выдать LazyTV за официальный клиент сервиса, чтобы пройти его проверку на посторонние приложения. Для меня это запрещённое действие независимо от согласия владельца, и дальше варианты обхода не обсуждаются. Смотреть эти сервисы — в LMD на приставке, где они уже работают под своим, официальным, доступом.

Законный путь для HDRezka, Zona, Zombie, Seasonvar-zone — только если владельцы этих сервисов дадут официальный API или ключ; без него эти источники в LazyTV не появятся. Пока смотреть их в официальных приложениях или в LMD на приставке.
