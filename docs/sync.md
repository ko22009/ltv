# Синхронизация между устройствами через Google Диск

Закладки, история просмотров, отметки просмотра, история поиска и часть настроек хранятся на Google Диске самого
человека, в папке `LazyTV` (`lazytv.json`). Своих серверов у приложения нет, данные между устройствами идут через
аккаунт владельца.

## Как работает

1. **Вход по коду.** Приложение просит у Google код, показывает его на экране (например `ABCD-EFGH`), человек
   открывает `google.com/device` на телефоне и вводит код. Приложение опрашивает Google и получает токен.
   Play Services не нужны: подходит старая приставка без сервисов Google, работает и на телефоне.
2. **Файл.** После каждой синхронизации в папку `LazyTV` кладётся новая копия `lazytv.json`, старая удаляется
   (копия создаётся раньше удаления, чтобы сбой загрузки не стёр прошлую). Папка видна в «Моих файлах», но приложение
   по праву `drive.file` видит только файлы, которые создало само.
3. **Слияние.** Каждое устройство хранит у себя копию, с которой обе стороны последний раз согласились
   (`sync`/`base`). При синхронизации считается, кто что поменял: изменение на одном устройстве побеждает
   неизменившееся значение на другом. Поэтому удаление закладки на телефоне не «всплывает» с приставки.
   Если обе стороны поменяли одну и ту же запись по-разному, побеждает то устройство, где сейчас идёт синхронизация
   (`SyncMerge.kt`, проверка `app/src/test/java/ru/lazytv/SyncMergeTest.kt`).
4. **При запуске** приложение тихо проверяет изменения, если связка настроена и с прошлой синхронизации прошло
   больше 10 минут (`Sync.startCheck`, вызов из `LazyApp`). Ошибка в этом месте не мешает работе и видна только
   в настройках строкой «Подключено. В … не вышло: …».
5. **Кнопка «Синхронизировать сейчас»** в настройках, раздел «Синхронизация».

## Что переносится, а что нет

| Переносится | Остаётся на устройстве |
| --- | --- |
| Закладки (все папки), история просмотров, отметки просмотра, история поиска | Адрес TorrServe, серверы JacRed, свой Jackett (адрес и ключ) |
| Уровень: язык, качество, озвучка, что предлагать первым, следующая серия сама, запоминать позицию, сортировка раздач, минимум сидов | Прокси и обход блокировок (у каждой сети и устройства своё) |
| Включённые сайты-источники (`service_*`) | Размер карточек (на телефоне и приставке разный), код родителя |
| | Позиции воспроизведения (устройства идут с разной скоростью) |

Список ключей настроек — `SYNCED_KEYS` в `Sync.kt`. Новый ключ, который имеет смысл на всех устройствах, туда
добавляется одной строкой; адреса и всё про сеть не добавляются никогда.

## Ключ Google (один раз на приложение)

Нужен OAuth-клиент типа «TVs and Limited Input devices» в своём проекте Google Cloud. Ключ приложения публичный,
он лежит в APK, поэтому в `local.properties` рядом с проектом:

```properties
DRIVE_CLIENT_ID=1234567890-абвгд.apps.googleusercontent.com
DRIVE_CLIENT_SECRET=GOCSPX-...
```

1. В [console.cloud.google.com](https://console.cloud.google.com) создать проект.
2. «APIs & Services» → «Library» → включить **Google Drive API**.
3. «OAuth consent screen»: тип External, заполнить название и почту; на шаге «Scopes» добавить
   `.../auth/drive.file`; на шаге «Test users» добавить свой аккаунт.
4. «Credentials» → «Create credentials» → «OAuth client ID» → тип **TVs and Limited Input devices**.
5. Скопировать client id и client secret в `local.properties`.

Пределы, о которых стоит знать:

- Вход по коду с телефона принимает не любое разрешение: `drive.appdata` (скрытая папка приложения) Google отклоняет
  с ошибкой `invalid_scope`, `drive.file` принимает. Поэтому файл лежит в обычной папке `LazyTV`, а не в скрытой.
  Проверено запросом к `https://oauth2.googleapis.com/device/code`.
- Пока приложение в статусе Testing, Google даёт вход на 7 дней, потом «Вход в Google истёк, подключите заново».
  Чтобы продлить, «Publish app» (без проверки Google будет предупреждение «unverified app», это нормально для
  домашнего приложения), либо повторять вход раз в неделю.
- В статусе Testing доступ только аккаунтам из списка test users (до 100).
- Разрешение только `drive.file`: чужие файлы на Диске приложению недоступны.

Без ключей раздел «Синхронизация» показывает «Не настроено в сборке: нет ключа Google», остальное приложение
работает как обычно.

## Где лежит и как убрать

- Токены: `SharedPreferences("sync")` в личной папке приложения (без шифрования; на устройстве без root их не видно).
- «Отключить Google» в настройках стирает токены и базовую копию на устройстве, папка `LazyTV` на Диске остаётся.
  Удалить её можно в [drive.google.com](https://drive.google.com): «Мои файлы» → папка LazyTV. Чтобы отозвать сам
  доступ, «Настройки» → «Управление приложениями» → LazyTV → удалить доступ.
